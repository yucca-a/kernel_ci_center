# 2026-09-09 LTS maintenance tools

These scripts were used to import and audit the following stable updates:

- SM8550: Linux 5.15.207 to 5.15.220
- SM8650: Linux 6.1.172 to 6.1.187
- SM8750: Linux 6.6.138 to 6.6.156

They intentionally retain the original workspace paths, version numbers, and
baseline commits so the completed update can be reproduced and audited. Adjust
those constants before reusing the scripts for a future update.
